Quick Start

Run this after every PC restart. Assumes JARs are already built.

First thing: Find your PC's local IP and note it. Run ipconfig and look for IPv4 Address starting with 192.168..

1. Check prerequisites

ItemCheck
SQL ServerGet-Service MSSQLSERVER — should be Running
Node.jsnode -v — should be v22+
Javajava -version
Redis exeC:\My Proj\redis-server\redis-server.exe should exist

2. Regenerate SSL certificate

cd "C:\My Proj\My project whatsapp"
node gen-cert.js

This auto-detects your current 192.168.x.x IP.

3. Start Redis

Start-Process -FilePath "C:\My Proj\redis-server\redis-server.exe" -WindowStyle Hidden

4. Start backend services (5 JARs)

$w = "C:\My Proj"
Start-Process -FilePath "java" -ArgumentList "-jar", "`"$w\whatsapp-auth\target\auth-server-0.0.1-SNAPSHOT.jar`"" -WorkingDirectory "$w\whatsapp-auth" -WindowStyle Hidden
Start-Sleep 8
Start-Process -FilePath "java" -ArgumentList "-jar", "`"$w\user-service\target\user-service-1.0.0.jar`"" -WorkingDirectory "$w\user-service" -WindowStyle Hidden
Start-Process -FilePath "java" -ArgumentList "-jar", "`"$w\media-service\target\media-service-1.0.0.jar`"" -WorkingDirectory "$w\media-service" -WindowStyle Hidden
Start-Sleep 5
Start-Process -FilePath "java" -ArgumentList "-jar", "`"$w\chat-service\target\chat-service-1.0.0.jar`"" -WorkingDirectory "$w\chat-service" -WindowStyle Hidden
Start-Process -FilePath "java" -ArgumentList "-jar", "`"$w\gateway-service\target\gateway-service-1.0.0.jar`"" -WorkingDirectory "$w\gateway-service" -WindowStyle Hidden

5. Serve Angular frontend

cd "C:\My Proj\My project whatsapp"
npx ng serve --host 0.0.0.0 --port 51772 --ssl --ssl-cert "certs/cert.pem" --ssl-key "certs/key.pem"

6. Open firewall ports (run as Admin)

New-NetFirewallRule -DisplayName "Connectly 8080-8084" -Direction Inbound -LocalPort 8080,8081,8082,8083,8084 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Connectly Frontend 51772" -Direction Inbound -LocalPort 51772 -Protocol TCP -Action Allow

7. Verify everything is running

netstat -an | Select-String ":808[0-4].*LISTEN"
Get-Process -Name "java","redis-server"

8. Access from any device

Open browser on another device on the same WiFi and go to:

https://192.168.0.104:51772

Accept the self-signed certificate warning (it's safe - your PC generated it).

Troubleshooting

Ports not listening after starting

  • Wait 15-30 seconds for Spring Boot to initialize
  • Check logs: Get-Content "C:\My Proj\logs\*.err"
  • Check if SQL Server is running

Cross-device "Connection refused"

  • Ensure both devices are on the same WiFi network
  • Run firewall rules as Administrator
  • Disable Windows Defender Firewall temporarily to test

WebSocket / STOMP connection fails

  • Check that gateway-service is running on port 8084
  • Check browser console for CORS errors
  • Use HTTPS (required for camera/mic access on other devices)

Self-signed cert warning

  • Click "Advanced" → "Proceed to site" in Chrome
  • This is safe - the cert is generated locally by gen-cert.js

Camera / Mic not working on other device

  • The page MUST be served over HTTPS (which it is via --ssl)
  • Accept the camera/mic permission prompt on the other device
